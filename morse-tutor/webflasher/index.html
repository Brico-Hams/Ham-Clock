Bricohams

Tu pantalla, tu elección: dos firmwares completamente independientes.

Grabar uno sustituye al otro. No es una actualización conjunta. Guarda antes la configuración y selecciona el modelo exacto de tu placa. No actives el borrado completo de flash salvo que quieras eliminar los ajustes guardados.

Ham-Clock

Reloj y dashboard de radio: propagación, DX, mapas y servicios conectados.

Instalar el reloj Abre el instalador existente de Ham-Clock. El tutor no modifica su firmware.

Morse Tutor

Aprendizaje Koch, recepción, práctica de envío, llave recta o palas, tarjeta SD y dos vías ESP-NOW.

Usa Chrome o Edge de escritorio con Web Serial.

El instalador necesita HTTPS (o localhost) y un navegador con Web Serial.

En el primer arranque, toca las tres cruces para calibrar el táctil. La llave física necesita GPIO libres y cableado adecuado; consulta el manual antes de conectar.
